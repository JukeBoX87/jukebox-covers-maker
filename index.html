🗂 GALERIE DE PROJETS

Cliquez ou F / Échap pour fermer
Principe
Crée des vignettes de genre/catégorie : une image sans texte de TMDB + un libellé en bas (police Ubuntu).
Étapes
Renseignez votre clé API TMDB (bouton 🔑) ; une coche ✓ apparaît quand elle est valide.
Choisissez Film / Série, le format Affiche 2:3 ou Paysage 16:9, et le Mode.
Tapez un titre : les résultats sortent instantanément. Cliquez-en un pour ouvrir l'éditeur plein écran.
Dans l'éditeur : la cover à gauche, les réglages (Édition) au centre, les vignettes sans texte à droite.
Exporter (PNG / JPEG) est en haut à droite de l'éditeur.
La croix ✕ ferme et revient à la recherche.
Modes
Covers : image + dégradé + libellé (mode complet).
Focus : l'image seule, sans texte ni dégradé — l'onglet Édition est masqué, on choisit juste la vignette.
Custom : compose un fond libre (recherche Pexels ou votre propre image) avec un clearart PNG transparent superposé et centré — typiquement une catégorie faite avec Clearart Maker. Réglez sa taille et sa position verticale, ainsi que le flou et l'assombrissement du fond ; les marges transparentes du clearart sont retirées automatiquement à l'import.
Astuces
🎲 Suggérer : tapez des mots clés (ex. « action », « braquage ») dans le champ dédié — l'outil propose une liste de films/séries à parcourir, et vous choisissez.
🚫 Animés / 🚫 Animation : excluent ces contenus du tirage aléatoire.
📁 Projets : enregistrez vos covers dans le navigateur, exportez / importez en .json pour les sauvegarder ou les transférer.
👁 aperçu plein écran (touche F).
🌙 / ☀️ thème sombre / clair (n'affecte pas l'image exportée).

À quoi sert le mode Custom ?
Il compose un fond libre (banque Pexels ou votre image) avec un clearart PNG transparent centré — typiquement une catégorie faite avec Clearart Maker. Réglez la taille et la position verticale du clearart ; les deux cadrages (Affiche 2:3, Paysage 16:9) sont disponibles.
Comment obtenir une clé API Pexels ?
Gratuite en deux minutes sur pexels.com/api. Créez un compte, cliquez « Get Started », puis remplissez le court formulaire :
• Project Name : un nom au choix (ex. « JukeBoX Covers »).
• Project Category : laissez « Personal Use / Just for Fun ».
• Explain briefly… (obligatoire) : une phrase suffit, par ex. « I use Pexels backgrounds in a personal tool to create cover images for my home media library. »
• URL : laissez vide, c'est facultatif.
• Cochez « I agree… » et générez.
La clé s'affiche aussitôt : copiez-la et collez-la ici via le bouton 🔑 Clé Pexels (mode Custom).
Différence entre Covers et Focus ?
Covers ajoute le dégradé et le libellé ; Focus exporte l'image sans texte telle quelle (utile comme fond ou vignette brute).
Aucune image ne s'affiche pour un titre ?
Ce titre n'a peut-être pas d'image sans texte dans ce format. Cochez « Inclure les images avec texte » ou changez de format / titre.
Comment sauvegarder mes covers ?
Via 📁 Projets : « Enregistrer » les stocke dans ce navigateur ; « Exporter » crée un fichier .json portable ; « Importer » les recharge (ici ou sur une autre machine).
Mes projets .json sont-ils lourds ?
Non : l'image n'est pas incluse, seul son lien TMDB est stocké — quelques Ko par projet. Il suffit d'avoir la clé API pour la recharger.
Comment changer Affiche ↔ Paysage sur un titre ouvert ?
Le choix du format est dans la barre de recherche : fermez l'éditeur (✕), changez le format, puis rouvrez le titre.
L'export échoue / image « salie » ?
C'est un blocage CORS sur l'image TMDB. Réessayez, changez d'image, ou choisissez une autre source.
Le mode clair change-t-il l'image exportée ?
Non : le thème ne touche que l'interface. Le rendu du canvas garde toujours ses couleurs.
Quels sont les réglages typographiques par défaut ?
Ubuntu Regular + faux gras, échelle verticale 150 %, interlettrage -2. Le faux gras est simulé par épaississement du tracé. La police se change via le bouton Police (recherche parmi ~1 900 familles Google Fonts, ou import de vos propres fichiers .ttf/.otf/.woff/.woff2) ; en mode 2 lignes, chaque ligne a ses propres réglages indépendants de police, couleur, taille, interlettrage, majuscules et faux gras (l'échelle verticale, l'interligne et la position verticale restent communes aux deux lignes). La graisse Light/Regular/Medium/Bold ne s'applique qu'à Ubuntu, les autres polices restent en Regular.
Où va ma clé API ?
Uniquement dans le stockage local du navigateur. La clé TMDB n'est envoyée qu'à TMDB, la clé Pexels qu'à Pexels — jamais ailleurs.
