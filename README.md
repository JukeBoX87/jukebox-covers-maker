# Covers Maker by JukeBoX

Générateur d'affiches/covers pour films et séries en un seul fichier HTML, sans dépendance ni build. Recherche via l'API [TMDB](https://www.themoviedb.org/) et images via [Pexels](https://www.pexels.com/), puis export en PNG.

## Utilisation

Ouvrez [`index.html`](index.html) dans un navigateur, ou via GitHub Pages : https://VOTRE-USER.github.io/jukebox-covers-maker/

Des clés API personnelles TMDB et Pexels sont requises (gratuites) et se configurent directement dans l'interface. Elles sont stockées uniquement dans le `localStorage` de votre navigateur, jamais transmises ailleurs.

## Fonctionnalités

- Recherche de films/séries par titre ou suggestion par mots-clés
- Modes Covers / Focus / Custom
- Formats affiche 2:3 ou paysage 16:9
- Personnalisation typographique (sélecteur de polices)
- Export en PNG
